LED Badge Reborn

Firmware para M5Stack ATOM Lite: controla el badge por infrarrojos desde el navegador.

  1. Conecta el ATOM Lite por USB.
  2. Cierra cualquier monitor serie que tengas abierto.
  3. Pulsa Instalar y elige el puerto usbserial.
Tu navegador no soporta Web Serial. Usa Chrome o Edge de escritorio. Solo funciona sobre HTTPS o en localhost.

Después de instalar

El cable ya no hace falta: el dispositivo levanta su propia red WiFi.

  1. Conéctate a la red LED-Badge-XXXX con la clave ledbadge.
  2. El panel de control se abre solo. Si no, entra a http://192.168.4.1.
  3. Desde ahí eliges efecto y categoría, y puedes darle las credenciales de tu WiFi para tenerlo en tu red (luego responde en http://led-badge.local).

Botón del dispositivo

  • Clic simple: envía el efecto actual y avanza al siguiente.
  • Doble clic: cambia de categoría.
  • Pulsación larga (3 s): olvida el WiFi y vuelve al portal.
  • LED: blanco = SPECIAL, verde = PULSO, azul = FADE. Destello rojo al enviar.
Instalación vía Web Serial. El firmware se descarga en tu navegador y se escribe directamente al dispositivo; no pasa por ningún servidor.
